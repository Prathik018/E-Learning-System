
#  E-Learning System
The E-Learning System is a comprehensive web-based application designed to eliminate the limitations of traditional manual learning systems. It provides a platform where students can learn a variety of subjects including programming, web development, art and design, and more — anytime and from anywhere. This system supports self-paced learning, offering a user-friendly interface to access course materials and track learning progress. The E-Learning System is developed using HTML, CSS, JavaScript, PHP, and MySQL to ensure a reliable, interactive, and efficient learning environment. HTML structures the content, CSS makes the platform visually appealing, and JavaScript enhances interactivity. On the backend, PHP handles logic and server-side operations while MySQL manages the data securely.
## Features
- Easy-to-use interface for student registration and course enrollment.

- Self-paced learning with anytime, anywhere access.

- Admin dashboard for course, student, and feedback management.

- Role-Based Access Control for students and administrators.

- Digital access to course materials and progress tracking.

- Feedback system for students to share their learning experience.

- Responsive design optimized for all devices.

## Tech Stack
Frontend:
- HTML5 for structuring web pages.

- CSS3 for styling and responsive design.

- JavaScript for interactivity and client-side validation.

Backend:

-  PHP for server-side logic and backend handling.

-  MySQL for database storage and management.
## Setup & Installation

To run the E-Learning System locally:

1. Clone the repository
```bash 
git clone https://github.com/Prathik018/E-Learning-System.git

```
2. Install a local server environment (XAMPP/WAMP recommended).

3. Move project files to the htdocs folder (for XAMPP) or equivalent.

4. Import the database:
- Open phpMyAdmin.

- Create a new database (e.g., elearning_db).

- Import the elearning_db.sql file from the project directory.
5. Run the project in the browser:
```bash
http://localhost/elearningsystem

```
